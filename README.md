# АгроМаркет API

## Запуск
npm install
npm run dev   # http://localhost:3000

## Эндпоинты

| Метод | Путь              | Описание               | Ответы    |
|-------|-------------------|------------------------|-----------|
| GET   | /api/health       | проверка сервера       | 200       |
| GET   | /api/products     | товары, ?search=       | 200       |
| GET   | /api/products/:id | один товар             | 200, 404  |
| GET   | /api/orders       | список заявок          | 200       |
| POST  | /api/orders       | новая заявка           | 201, 400  |

## Лабораторная 5 — ответы

- Content-Type у res.send и res.json: text/html; charset=utf-8 у res.send со строкой и application/json; charset=utf-8 у res.json.
- Что происходит без next() в middleware: запрос «зависает», потому что middleware не ответил и не передал запрос дальше по цепочке.
- Логгер после маршрутов: запросы к существующим маршрутам не логируются, так как обработчик уже отправил ответ и не вызвал next().
- Отправка формы без express.json(): сервер отвечает 400, потому что req.body пустой (undefined), тело JSON не разобрано.
- Использовал ИИ: для понимания и решения ошибок
